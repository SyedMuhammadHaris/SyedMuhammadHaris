## About Me

I'm a software engineer based in Karachi, Pakistan, working across the full stack, including backend systems, APIs, and web frontends. My core stack is Python and Django on the backend, paired with React and Next.js on the frontend, backed by PostgreSQL and Firebase.

AI is a standard part of how I build software today, not a separate skill I dabble in. I use AI tools throughout the development process, from planning and writing code to debugging and reviewing it, the same way earlier generations of developers treated version control or automated testing as simply part of the job. That includes working directly with agentic coding tools and structuring my workflow around them where it makes sense.

I think of myself less as someone who just writes code and more as someone who solves problems end to end. With AI narrowing the gap between idea and implementation, understanding the product (why something is being built and for whom) matters as much as how it's built. I try to bring that product-level thinking into everything I work on, not just the engineering side of it.

- Building full-stack applications with **Django REST Framework** and **Next.js**
- Working with AI-assisted and agentic development tools as part of my regular workflow
- Open to collaborating on projects regardless of stack, happy to pick up new tools where the problem calls for it
